Authentication

Five user types.
One mobile OTP system.

All logins use phone-based OTP via SMS. Email OTP removed. WhatsApp OTP is next.

👤
User Active
Phone OTP login & signup with Cloudinary profile upload, GST, geo-location, and JWT token (3-day expiry).
POST /api/auth/login
🏪
Seller Active
Phone OTP login. Cloudinary profile, GSTIN, location & service area. Verified seller badge.
POST /api/seller/login
🏗️
Builder Active
Phone OTP login. License number, project types, team size, min/max project value & geo-radius.
POST /api/builder/login
🧱
Masonry Active
Phone OTP login. Specializations, daily/project rates, experience years & geospatial search.
POST /api/masonry/login
🔐
Admin Active
Email + password login with MD5-hashed credentials. JWT token with isAdmin role claim.
POST /api/admin/login
💬
WhatsApp Login Coming Soon
WhatsApp OTP will replace SMS across all 5 user types — higher delivery rates, richer flows, and chat-based support.
